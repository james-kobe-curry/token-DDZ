# DouZero WP model notice

The three ONNX files in this directory are converted copies of the pretrained
DouZero winning-percentage (WP) baselines from the official DouZero project:

- Project: https://github.com/kwai/DouZero
- Paper: https://proceedings.mlr.press/v139/zha21a.html
- License: Apache License 2.0

The ONNX copies were downloaded from the `palemoky/douzero-baselines`
Hugging Face mirror so they can run locally in a browser and Android WebView.
That mirror is a distribution source, not the upstream project.

The model files and this application code remain subject to their respective
licenses. See `LICENSE-DOUZERO` in this directory for the upstream license.
