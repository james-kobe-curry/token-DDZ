# Token 斗地主

一个原创的轻赛博国潮斗地主网页 MVP。Token 是不可购买、不可提现、不可转赠的游戏积分，仅用于兑换站内装扮。

## 已实现

- 经典三人斗地主与排位入口
- 确定性洗牌、开局摘要和结束后种子验证
- 叫地主、底牌、常用完整牌型、牌型比较、炸弹倍数与胜负结算
- 两名本地策略机器人，可选择超强人机、大师、精英、普通与菜鸟五档强度
- 每日任务、Token 奖励、排位分、战绩和藏品商城
- 浏览器本地存档和桌面/移动端响应式布局
- 深墨绿、暗朱红和暖金配色的国潮轻奢实战牌桌
- 回合倒计时、重新选牌、聊天、音效、设置和短促牌型粒子动效
- 错峰发牌、按玩家方向飞入的出牌动画、动态光环、绒布流光与低频环境漂浮
- 三座位独立出牌区，以及叫分、不出、报单、报双等座位动作气泡
- 单击、横向拖动、双击同点数和键盘选牌，选牌过程实时识别牌型与压制关系
- 牌型状态操作台、非法选择抖动反馈、地主揭晓与炸弹环境冲击演出
- 使用 Web Audio 生成分牌、单张、对子、三张、连牌、炸弹与胜负等分层牌桌音效，并根据左右座位提供方向感
- 支持叫分、地主揭晓、牌型、不出、报单/报双、回合接管和胜负中文语音；操作音效与牌局语音可分别关闭
- 具有阵营意识的规则机器人：农民会识别队友牌权，并在对手报单时调整炸弹策略
- 机器人跟牌优先使用独立单张并保留对子、三张和炸弹；对手报单/报双时会使用最高安全牌主动封堵
- 高阶机器人进入十二张以内会搜索整手牌最少出牌手数，前中盘使用快速结构、记牌与牌权评估
- 20 秒超时托管、最近四步牌路记录和保持点数递减的智能分组
- 出牌、过牌和叫分具有原子动作锁，能拦截鼠标、键盘与超时托管造成的重复提交
- 春天与反春天翻倍结算，以及胜局、倍数、排位、春天四类 Token 奖励明细
- 智能匹配可根据部分选择自动补全对子、顺子、连对等合法牌型，并为三张等完整牌型提供扩展候选
- 智能匹配遵循手动操作优先：玩家主动取消或重选后不会把牌重新抢选回来
- 横向滑动结束后按重合度、补牌数量和牌型价值自动吸附最佳方案；可丢弃无法并入的杂牌，也可补成长顺
- 实战牌桌提供持续报单/报双警戒、最后五秒紧急倒计时和更明确的自由出牌/跟牌目标提示
- 回合接管系统将牌桌金边、手牌、操作台、独立双音与触感统一联动；主倒计时直接位于出牌指令条
- 跟牌时同时展示目标牌面、目标/当前牌型对比和合法状态，非法选择可一键修正为最小合法方案
- 智能补牌先以金色虚影标记即将加入的牌，再完成选择，避免无提示地改变玩家手牌状态
- 手牌由左至右渐进缩小，选中牌保持独立上浮；支持 H 提示、P 不出、Enter 出牌和 Esc 重选快捷键
- 智能策略优先保留炸弹、王炸、三张和对子，带牌时先使用真正的单张或对子
- 智能提示按拆牌代价、预计剩余手数、控制牌价值、对手收官风险和队友配合综合排序；同等策略价值时优先较小的牌，Shift+H 可跳到下一牌型
- 三带一、三带二、飞机翅膀和四带二会枚举全部合法带牌组合，不再只给出最低带牌
- 本桌规则明确锁定顺子/连对/飞机最短长度、四带二携带对子与飞机核心点数复用限制，并可在设置内查看
- 两家连续不出后会短暂展示牌权归还与新一轮提示，机器人思考状态使用独立节奏反馈
- 牌桌出牌区使用更大的牌面、点数和花色，并根据出牌张数动态压叠；顺子与飞机不会超出主要牌桌区域
- 出牌标签同步显示玩家、牌型和张数，跟牌操作台会自动隐藏重复说明，只保留目标比较与关键操作
- 结算页支持完整牌局复盘：逐步还原叫分、地主确定、出牌、不出、倍率和三家剩余手牌
- 复盘时间轴支持点击跳转、上一步/下一步、自动播放、键盘方向键与空格控制，并关联公平摘要
- 战术复盘会评价每次出牌与不出，标记过早炸弹、拆炸弹/三张/对子以及放过关键牌权等问题
- 每个关注节点提供更稳健的推荐牌路；时间轴使用绿、金、红节点区分稳健、可关注和高风险决策
- 商城藏品支持购买后反复装备，已装备牌背会同步到地主牌和对手牌堆
- 操作音效、牌局语音、触感反馈、智能理牌、智能匹配、AI 强度和动态效果均为真实设置并在浏览器持久化
- AI 只使用自己的手牌、公开底牌、已出牌记录与三家剩余张数；难度越高，记牌完整度、终局搜索深度和队友协作可靠度越高
- 超强与大师将完整王炸作为受保护结构，领牌、跟牌和终局搜索都不会把双王拆成单王；精英以下按难度保留受控失误
- 超强会从未知牌中生成 72 组符合公开信息与剩余张数的可能分配，估算对手接牌率和己方重新夺回牌权的概率；大师、精英和普通依次降低采样数量
- 出牌与不出进入同一策略排名，能判断队友牌权、地主报单、炸弹消耗和主动接牌封堵，不再把过牌当作无合法牌时的兜底
- 顺子、连对、飞机、对子、三张、炸弹和王炸均纳入结构保护；非紧急局面存在完整方案时，高阶 AI 不会拆散组合
- 超强计算运行在独立 Web Worker 中；玩家操作台异步展示首选、稳健、激进三条建议以及结构损失原因
- `npm run benchmark:ai` 可运行固定种子、地主/农民角色互换的五档 AI 自对战基准
- 支持系统“减少动态效果”偏好与游戏内动态效果开关，保证舒适度和可访问性
- Android 触屏选牌改为基于手牌几何位置的逐帧命中，快速横滑会补齐跨过的牌，不再依赖触屏端不稳定的悬停事件
- AI 回合不再清空玩家的选择；等待出牌期间可点选、滑选和循环智能预选，到自己回合后按最新目标牌重新校验
- 智能提示保留多条结构化合法候选，并按普通牌优先、点数由小到大、炸弹和王炸靠后的顺序持续循环
- 结算页提供右上角关闭和返回大厅双入口，Android 物理返回键与页面状态同步更新，一次即可离开牌局
- 叫地主与出牌统一按逆时针轮转：自己 → 右侧玩家 → 左侧玩家；AI 的下家判断和队友配合使用同一顺序

好友房、真人匹配、账号系统和服务端签名属于联机版本范围，当前界面中已清晰标记，未伪装成可用功能。

苹果与安卓在同一局域网内跨平台联机是可实现的。推荐采用“房主手机权威主机 + WebSocket 实时消息 + 二维码/房间码发现”的方案；当前版本尚未开放好友房，完整的消息协议、权限和断线恢复方案见 [局域网联机设计](docs/LAN_MULTIPLAYER.md)。

## 运行

```bash
npm install
npm run dev
```

打开 `http://localhost:5173`。

需要直接进入实战界面进行设计预览时，可打开 `http://localhost:5173/?play=1`。

## 验证

```bash
npm test
npm run build
```

生产文件输出到 `dist/`。

## Android APK

项目已接入 Capacitor Android，并针对手机横屏、刘海安全区、沉浸式全屏、物理返回键、原生触感和系统中文语音合成做了适配。Android 版还使用独立的轻量渲染配置，减少大面积模糊与持续合成动画，并为 20:9、16:9 和 720p 横屏提供紧凑布局；对局提示、玩家身份、设置面板和结算页也使用统一的手机端信息层级。

```bash
npm run build
npm run android:sync
npm run android:build
```

可安装的调试包输出到 `android/app/build/outputs/apk/debug/app-debug.apk`。该版本使用 Android 调试签名，适合本机安装试玩；发布到应用商店前需要配置正式签名并构建 release 包。
